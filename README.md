# Cambio de Texto en una Etiqueta mediante Botón en Java

## Descripción

Este proyecto consiste en desarrollar una aplicación en **Java** con una interfaz gráfica que incluye un **botón** y una **etiqueta (`JLabel`)**. Al pulsar el botón, el texto mostrado en la etiqueta cambia dinámicamente.

El objetivo del ejercicio es practicar la manipulación de componentes gráficos y el manejo de eventos utilizando **Swing**.

## Objetivos

- Crear una interfaz gráfica básica en Java.
- Implementar un botón con gestión de eventos.
- Mostrar una etiqueta en la ventana.
- Modificar el texto de la etiqueta al pulsar el botón.
- Comprender la interacción entre componentes gráficos.

## Funcionamiento

1. Se inicia la aplicación.
2. Se muestra una ventana con una etiqueta y un botón.
3. La etiqueta contiene un texto inicial.
4. El usuario pulsa el botón.
5. El texto de la etiqueta cambia automáticamente.

## Ejemplo de uso

Estado inicial:

```text
+--------------------------------+
|                                |
|     Texto inicial             |
|                                |
|   [ Cambiar texto ]           |
|                                |
+--------------------------------+
```

Después de pulsar el botón:

```text
+--------------------------------+
|                                |
|     Texto actualizado         |
|                                |
|   [ Cambiar texto ]           |
|                                |
+--------------------------------+
```
